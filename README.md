# Unity Basics - Part 1

## מה יש בפרויקט

רכיבים בסיסיים ב-Unity:

1. Oscillator - תנועת מטוטלת
ניתן לבחור בו את הכיוון, את אורך אורך התנועה ואת הקצב(מהירות)
2. Rotator - סיבוב
ניתן לבחור בו סביב איזה ציר הוא מסתובב ומהירות הסיבוב
3. Pulsator - פעימה (גדל וקטן)
ניתן לבחור בו את גודל הפעימה(הגודל המינימלי והמקסימלי בכל פעימה) ואת קצת הפעימות
5. HideShowToggle - הסתרה והצגה בלחיצת רווח
בעזרת כפתור ה"רווח" ("Space") ניתן לבלות ולהסתיר את האובייקט.
